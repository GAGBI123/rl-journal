## What's new

- **Training routines.** Save the trainings you do and for how long (Routines in the sidebar), then start a routine on any day and work through the checklist. Press Start to run each item's timer; with Auto-next the next one starts by itself when a timer ends.
- **Minutes only.** Time is always entered in minutes now (hours are gone). Totals show nicely as days, hours and minutes, like 1d 4h 20m.
- **Stop the timer from the app.** The top bar has a stop button next to pause, and the day page shows the running timer with Pause, Stop & log and Cancel.
- **Any shortcut you want.** In Settings, click a shortcut and press any key or combination (F9, Ctrl + Shift + K, …). The app tells you if another program already uses it.
- **Pause fixes.** The overlay buttons react to every kind of press and flash when the press arrives (also for the shortcut). In game, use the shortcut: the game keeps the mouse to itself, so clicks often can't reach the overlay. Shortcuts now also work on Linux with Wayland (KDE, GNOME).
- **Season suggestions.** New season fills in the current Rocket League season with its real start date and length. If you already have it, it suggests the seasons before it. Past seasons are added as completed.
