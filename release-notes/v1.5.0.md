## What's new

- **Routines: amounts and stopwatch items.** A routine item can now be a number of minutes, an amount (for example 50 shots in a training pack), or a stopwatch for things with no set time. Amount items are ticked off (or press the pen to log how many you really did). Stopwatch items run a stopwatch that you stop when you're done, and Auto-next starts them like timers.
- **Routines count what you already did today.** When you add a routine to a day, anything you already logged that day counts towards it. Items you already did are ticked off, partly done ones show what's left (and their timer only runs for the rest), and if you did more than the routine asks, the item shows what you really did, like 80× / 50×.
- **Tracked matches: newest first, and you can fold them away.** On the day page, the latest match is now at the top. Click the Tracked matches header to hide or show the list (the header still shows how many matches and your wins and losses). The app remembers your choice.
